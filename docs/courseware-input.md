# Courseware Input Contract

Version one accepts Markdown or structured text. Supply a title, intended audience, ordered section headings, an explanatory claim per section, and any source facts that must appear. Use headings to establish sequence; put diagrams, comparisons, processes, timelines, charts, and simulations in plain language under the relevant heading.

The generator first writes a deck brief, then chooses a page primitive for each claim. Use a custom module only when a primitive cannot explain the interaction. It must not preserve source wording blindly or invent facts.
