# Agent Engineering, Made Visible

Audience: engineers preparing a short technical briefing about LangGraph, LangChain v1, and Deep Agents.

## Map three collections to one progression

Start at model calls, move through graph orchestration, then cross into production boundaries.

## Compare reading with orchestration

Knowledge Notes is the reading layer; this deck is the explanation layer. Both point back to source material.

## Work in a deliberate sequence

Frame the model call, add state, bind tools, observe the loop, and test failure paths.

## Keep the reasoning visible

State, middleware, memory, and remote contracts make an agent explainable after it leaves the notebook.
